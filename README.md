# AEMBR — 耦合振荡器推理引擎

**蒸馏替代训练 · 相位同步替代矩阵乘法**

---

## 一句话

等效大语言模型的语义推理，仅需 **KB 级内存**、**手机 CPU**。不需要训练。不需要 GPU。

---

## 核心机制

```
Transformer:   输入 → 矩阵乘法 → softmax → 输出  (O(N²)，需要 GPU)
AEMBR:         输入 → 相位扰动 → sin共振收敛 → 解码  (O(E)，纯 CPU)
```

J 矩阵（语义耦合拓扑）从 BERT 嵌入一次性蒸馏，不需要反向传播训练。
