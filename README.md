# AEMBR — 耦合振荡器推理引擎

**蒸馏替代训练 · 相位同步替代矩阵乘法 · 30MB 替代 140GB**

---

## 一句话

等效 70B 参数的大语言模型推理，仅需 **30MB 内存**、**340M FLOPs**、**手机 CPU**。不需要 GPU。不需要数据中心。

---

## 核心理念

```
Transformer:   输入 → 浮点向量 → Q·K^T/√d → softmax → 加权V → 输出 (O(N²))
AEMBR:         输入 → 相位扰动 → 约束传播·sin共振 → 解码 (O(E), E≪N²)
```

知识已经在语言结构里。不需要反向传播来提取——只需蒸馏拓扑、让物理收敛。

## 快速开始

```bash
# 安装依赖
pip install numpy jieba torch transformers scikit-learn

# 蒸馏拓扑
python aembr_v0.6c_bert.py   # BERT嵌入 · 500节点 · 21秒

# 优化拓扑
python aembr_optimize.py     # 领域聚类 · 度优化 · O1+O7

# 800节点全管道
python aembr_800_final.py    # 蒸馏 · 聚类 · 推理 · 一键输出
```
